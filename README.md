# Mission: Soil Sleuth

Mobile-first web game based on the supplied "Spot the Threat" concept and storyboard.

## Run locally

```bash
npm install
npm run dev
```

## Test

With the dev server running on port 5173:

```bash
npm run test:e2e
```

## Global leaderboard

The app runs with a demo leaderboard by default. To enable a real global leaderboard:

1. Create a Supabase project.
2. Add this table:

```sql
create table leaderboard (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default now(),
  name text not null,
  region text,
  score integer not null,
  case_id text
);
```

3. Copy `.env.example` to `.env.local` and add:

```bash
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

4. Deploy to Vercel or Netlify and set the same environment variables there.

## GitHub Pages

This project includes a GitHub Pages workflow. After pushing to a GitHub repository:

1. Open the repository on GitHub.
2. Go to Settings > Pages.
3. Under Source, choose "GitHub Actions".
4. Push to the `main` branch.

GitHub will publish the game at a URL like:

```text
https://your-username.github.io/your-repo-name/
```
